# Assets

## Structure

- `images/` - Images alphabet LSF (a.png → z.png)
- `videos/` - Vidéos alphabet LSF (a.mp4 → z.mp4)

## Format

- **Images**: PNG, 1000x1000px, < 100 KB
- **Vidéos**: MP4 H.264, 720p+, 3-5s, < 500 KB

## Note

Les fichiers actuels sont des placeholders à remplacer par de vraies vidéos LSF.
